# Home Assistant Add-on: STsup

Швидкий та легкий трекер завдань (Jira / Linear альтернатива) прямо у вашому Home Assistant.

## Встановлення

1. У Home Assistant перейдіть до: **Налаштування** $\rightarrow$ **Додатки (Add-ons)** $\rightarrow$ **Магазин додатків (Add-on Store)**.
2. У правому верхньому кутку відкрийте меню (три крапки) $\rightarrow$ **Репозиторії (Repositories)**.
3. Вставте посилання на ваш репозиторій:
   ```text
   https://github.com/S88EM/STsupp
   ```
4. Натисніть **Додати (Add)** та оновіть сторінку.
5. Знайдіть **STsup** у списку додатків, відкрийте його та натисніть **Встановити (Install)**.
6. Натисніть **Запустити (Start)** та **Відкрити веб-інтерфейс (Open Web UI)**.

## Можливості

- Вбудована база даних PostgreSQL (усі дані зберігаються у захищеній директорії `/data` та автоматично входять у бекапи Home Assistant).
- Повний функціонал: Kanban-дошка, кастомні колонки, чек-листи, скріншоти та готовність до підключення Confluence MCP.

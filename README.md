# STsup — Швидкий Self-Hosted Трекер Завдань (Linear / Jira альтернатива)

Легкий, швидкий і гнучкий інструмент управління задачами для внутрішніх команд, оптимізований для низького споживання оперативної пам'яті (~100-150 МБ RAM).

---

## 🌟 Основні можливості MVP

- **Гнучкий воркфлоу (Workflow):** кожен проект може мати власні кастомні колонки та статуси з індивідуальними кольорами.
- **Швидка Kanban-дошка:** плавне перетягування карток (Drag-and-Drop) із миттєвим збереженням порядку.
- **Два режими перегляду:** швидке перемикання між **Дошкою (Kanban)** та **Списком (List view)**.
- **Детальна картка задачі:**
  - Пріоритети (*Low, Medium, High, Urgent*);
  - Чек-листи та підзадачі з індикатором прогресу;
  - Коментарі та обговорення;
  - Вставка скріншотів прямо з буфера обміну (`Ctrl+V`);
  - Дедлайни та виконавці.
- **💡 Інтеграція з Confluence через MCP (Model Context Protocol):**
  - Готова архітектура для підключення Confluence MCP сервера;
  - Автоматичний пошук релевантних інструкцій та регламентів у базі знань Confluence прямо з картки задачі;
  - Відображення посилань на статті та генерація AI рекомендацій для вирішення задачі.
- **Гарячі клавіші:** натискання `C` відкриває вікно створення нової задачі (у стилі Linear).
- **Кросплатформеність:** працює на Windows, Linux, macOS та на домашньому сервері **Home Assistant** (x86_64 та ARM64).

## 🚀 Швидкий запуск через Docker Compose (Рекомендовано)

Найпростіший спосіб запустити систему разом із базою даних PostgreSQL:

```bash
docker compose up -d
```

Після запуску відкрийте браузер:
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🛠 Локальна розробка (без Docker)

### 1. Встановлення залежностей:
```bash
npm install
```

### 2. Налаштування змінних оточення:
Створіть файл `.env` на основі `.env.example`:
```env
DATABASE_URL="postgresql://stuser:stpassword@localhost:5432/stsup_db?schema=public"
PORT=3000
```

### 3. Генерація клієнта БД та міграція:
```bash
npx prisma db push
npm run db:seed
```

### 4. Запуск сервера розробки:
```bash
npm run dev
```

## 🏠 Розгортання на Home Assistant

Завдяки ощадливому використанню ресурсів STsup можна запустити безпосередньо на Home Assistant:
1. **Через Portainer / Docker:** додайте `docker-compose.yml` у стек Portainer.
2. **Через локальний Add-on:** покладіть репозиторій у папку `/addons/stsup` та запустіть як локальний додаток.

---

## 🧠 MCP (Model Context Protocol) & Confluence

Система підтримує підключення Confluence MCP сервера. У `.env` файлі достатньо вказати адресу MCP сервера:
```env
CONFLUENCE_MCP_SERVER_URL="http://your-mcp-server:8000"
```
Після цього у кожній задачі з'явиться можливість в 1 клік отримати AI-аналіз завдання на основі корпоративної бази знань Confluence.

## 📌 Активний беклог

### 1. [ST-4] Налаштування поштового сервера (SMTP) та першого адміна через файл конфігурації
* **Пріоритет:** `HIGH`
* **Статус:** `В беклозі (Готово до реалізації)`
* **Опис вимог:**
  - Налаштування підключення до існуючого поштового сервера мають знаходитися виключно у файлі конфігурації (`.env` для локального запуску/Docker та `config.yaml` / `/data/options.json` для Home Assistant).
  - Перший користувач системи (Admin) також має задаватися через файл конфігурації (`ADMIN_EMAIL`, `ADMIN_NAME`, `ADMIN_PASSWORD`), щоб не хардкодити дані в коді.
  - Модуль надсилання пошти (Nodemailer):
    - Реєстрація користувачів та підтвердження email.
    - Відновлення та скидання забутого пароля через безпечне одноразове посилання.
    - Сповіщення користувачів на пошту (призначення задачі, зміна статусу, нові коментарі, наближення дедлайну).
* **Чек-лист підзадач:**
  - [ ] Додати змінні SMTP та першого адміна до файлу конфігурації (`.env.example`, `config.yaml`)
  - [ ] Реалізувати сервіс `src/lib/email.ts` на базі Nodemailer із підтримкою SMTP Host, Port, User, Password, SSL/TLS
  - [ ] Оновити модель даних Prisma (`User`: `passwordHash`, `resetToken`, `resetTokenExpires`)
  - [ ] Реалізувати API та інтерфейс відновлення пароля (`/forgot-password`, `/reset-password`)
  - [ ] Реалізувати відправку email-сповіщень при зміні статусів та коментарях
